# محاسبه آنالیز ذوب (نسخه ۲)

محتوای این پوشه هم وب‌اپلیکیشن را آماده می‌کند و هم فایل نصبی اندروید (APK). هر دو کار را GitHub به صورت خودکار و رایگان انجام می‌دهد.

## مرحله ۱: وب‌اپلیکیشن (نصب از مرورگر)
1. در github.com حساب بسازید و یک ریپازیتوری جدید با نام `melt-analysis` بسازید.
2. در صفحه ریپازیتوری روی «uploading an existing file» بزنید و **همه محتوای این پوشه** را بکشید و رها کنید. پوشه `.github` را هم حتماً بفرستید (پوشه مخفی است؛ در ویندوز گزینه نمایش فایل‌های مخفی را روشن کنید). بعد Commit بزنید.
3. در ریپازیتوری به Settings ← Pages بروید و Source را روی **GitHub Actions** بگذارید.
4. در تب Actions صبر کنید تا کار سبز شود. آدرس سایت این شکلی است:
   `https://نام‌کاربری.github.io/melt-analysis/`
5. آدرس را روی گوشی در **Chrome** باز کنید. از منوی سه‌نقطه «نصب برنامه» یا «افزودن به صفحه اصلی» را بزنید.
   بعد از اولین باز شدن، برنامه **بدون اینترنت** هم کار می‌کند.

## مرحله ۲: فایل APK
1. همان کار Actions بعد از ساختن سایت، فایل APK را هم می‌سازد (حدود ۵ تا ۸ دقیقه).
2. در تب Actions روی آخرین اجرا بزنید. پایین صفحه در بخش Artifacts فایل `melt-analysis-apk` را دانلود کنید.
3. فایل zip را باز کنید و `melt-analysis.apk` را به گوشی منتقل و نصب کنید. اندروید اجازه «نصب از منابع ناشناس» را می‌خواهد؛ آن را تأیید کنید.

## نکته‌ها
- سوابق روی همان گوشی ذخیره می‌شود. وب‌اپلیکیشن و APK حافظه جداگانه دارند؛ یکی را انتخاب کنید یا از هر دو خروجی CSV بگیرید.
- اگر برنامه را پاک کنید یا داده‌های Chrome را پاک کنید، سوابق هم پاک می‌شود. هر چند وقت یک بار از بخش سوابق خروجی CSV بگیرید.
- برای تغییر فایل‌ها، فایل جدید را در ریپازیتوری آپلود کنید. در `www/sw.js` عدد `melt-analysis-v2` را یکی بالا ببرید تا گوشی‌ها نسخه جدید را بگیرند. APK هم دوباره ساخته می‌شود.
- APK این مرحله نسخه Debug است و برای استفاده داخلی کارخانه کافی است. برای انتشار در کافه‌بازار یا گوگل‌پلی باید امضای Release اضافه شود.
